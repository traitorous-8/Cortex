# Cortex-Core

**Cortex-Core: система компьютерного зрения для контроля соблюдения техники безопасности — выявляет и подтверждает нарушения (отсутствие СИЗ) по видео с существующих камер объекта.**

## Как это работает

Пайплайн работы Cortex-Core состоит из следующих этапов:
1. **Детекция**: YOLOv8 распознаёт ключевые объекты на кадре (человек, каска, жилет).
2. **Трекинг**: отслеживание объектов между кадрами для привязки их к конкретному человеку.
3. **Слой верификации**: анализ обнаруженных несоответствий.
4. **Формирование отчёта**: генерация PDF-отчёта с подтверждёнными нарушениями.

**Ключевое отличие — слой верификации.**
Обычный детектор даёт много ложных тревог (ложных срабатываний), из-за которых подобные системы часто отключают или игнорируют. Слой верификации в Cortex-Core подтверждает каждое нарушение по зоне, устойчивости во времени (гистерезис) перед тем, как окончательно его зафиксировать, существенно снижая количество ложных срабатываний.

## Архитектура

Основные модули системы:
* `detect.py` — обёртка над моделью детекции объектов (YOLOv8).
* `violation.py` — логика определения базовых нарушений (наличие/отсутствие СИЗ на человеке).
* `verify.py` — слой верификации и фильтрации нарушений во времени.
* `pipeline.py` — связующее звено, сквозной процесс обработки видео от кадра до отчёта.
* `report.py` — генерация PDF-отчёта с кадрами нарушений.
* `cli.py` — интерфейс командной строки (CLI) для запуска системы.

## Статус проекта

Ранняя стадия. На данный момент реализовано:
* Обученная модель детекции СИЗ (85–89% mAP по классам: каска, жилет, человек).
* Протестированный слой верификации (юнит-тесты проходят).
* Рабочий сквозной пайплайн: загрузка видео → обработка → PDF-отчёт.

## Установка и использование

Установите пакет в режиме редактирования:

```bash
pip install -e .
```

Запуск пайплайна через командную строку:

```bash
cortex-detect --video VIDEO --weights MODEL.pt --output report.pdf --site "Название объекта"
```
